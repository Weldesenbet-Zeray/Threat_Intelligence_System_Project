General Instructions (Applicable to ALL Groups)  

Each group has been hired as a cybersecurity consulting team to assess and improve the security  

of a client's big data environment.  

Every project must include the following:  

Part A – Environment Setup  

Build a small working environment using open-source software. The environment should  

include:  

 A data source (CSV, JSON, logs, or sensor data)  

 A storage platform (PostgreSQL, SQLite, MongoDB, or MinIO)  

 One or more security tools  

 Logging capability  

Docker or VirtualBox may be used but are not mandatory.  

Part B – Dataset  

Use a public dataset or generate your own using Python.  

Minimum size: 100,000 records.  

Part C – Security Controls  

Implement security controls relevant to your assigned scenario.  

Examples include:  

 Authentication  

 Role-based access control  

 Encryption  

 Integrity verification  

 Logging  

 Malware scanning  

 Network monitoring  

 Backup and recovery  

Part D – Security Testing  

Perform at least six security tests.  

For each test, include:  

 Objective  

 Procedure  

 Expected result  

 Actual result  

 Evidence (logs, screenshots, dashboards, or terminal output)  

Part E – Recommendations  

Discuss:  

 Vulnerabilities identified  

 Remaining risks  

 Improvements that should be implemented
