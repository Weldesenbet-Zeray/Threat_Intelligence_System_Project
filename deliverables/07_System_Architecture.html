System Architecture — Common Deliverable

Threat Intelligence Investigation Environment

DSA 4030 Big Data Security · Group 13. Pipeline from synthetic log generation through storage, rule-based detection, external threat-intelligence enrichment, and the security-control layer wrapped around all of it.

Scenario: Suspicious IP Investigation Storage: SQLite Dataset: 135,000+ records Controls: 5 implemented
Pipeline

End-to-end data and control flow

Logs are generated, stored, screened by six detection rules, enriched against two free threat-intel sources, scored, and surfaced to a dashboard — with encryption, access control, integrity checks, logging, and backup wrapped around the storage and enrichment stages.
